## 官网首页（/zh/siteNew）登录后按钮改为 Start，点击直达当前场景页

需求：首页大标题下方主按钮「Sign in」在用户已登录时不再显示，改为「Start」；点击 Start 跳转到当前生效场景的首页。

改动文件：

- `src/pages/zh/siteNew/index.vue`
  - 主按钮改为未登录渲染 `nuxt-link`（Sign in，跳原 SSO 登录地址 `http://oort.oortcloudsmart.com:23410`），已登录渲染 `div`（Start，`@click="handleStart"`）。
  - 新增 `handleStart`：`getLastIndustry(auth, entityId)` 取当前生效 `industry_id` → `getMyIndustryList(auth)` 取 `hyConfig/cjConfig/znConfig` 合并 → 按 id 匹配 → `buildIndustryHomepageUrl(getIndustryHomepageUrl(item))` → `window.location.href` 跳转。
  - 兜底：没有当前生效场景 / 场景未配置首页 / 接口异常时，打开「场景选择」弹框让用户先选。
  - `auth` 取自 sessionStorage `accessToken`/`tenantId`，回退 `route.query.access_token/tenant_id`（与 NavHeader 一致）。
- `src/components/siteNew/NavHeader.vue`（两处 `ref` → Nuxt `useState`，实现跨组件共享）
  - `userInfo` → `useState('siteUserInfo', () => null)`：首页据此判断登录态。
  - `industryVisible` → `useState('siteSceneDialogVisible', () => false)`：首页兜底时复用 NavHeader 里同一个「场景选择」el-dialog（内含 ChangeHYRight）。

关键结论 / 约定：

- 登录态唯一来源仍是 NavHeader（verifyToken + getUserInfo + 10s 轮询 + focus/storage 事件）；首页只读共享状态，不重复请求 SSO，登出/切号会经 `resetLoginState` 自动把按钮切回 Sign in。
- 用 Nuxt `useState`（auto-import，项目无 composables 目录、pinia 未注册为 Nuxt 模块），键名：`siteUserInfo`、`siteSceneDialogVisible`。
- `NavHeader.vue` 的仓库 blob 是**混合换行符**（939 CRLF + 38 LF）。用编辑器/脚本整体改写会把整个文件变成 LF，产生约 1900 行的假 diff；改这个文件时必须保持原有换行符风格（本次已还原，diff 为 4+/2-）。
- 校验：`eslint` 0 error；`git diff --check` 会因 CRLF 对新增行报 trailing whitespace（该文件历史遗留现象）。
